# superLane's AI & Modern Landscape Blog

A personal website showcasing my perspectives on artificial intelligence and contemporary technological developments.

## 🚀 Quick Start

This is a static website built with HTML and CSS. To get started:

1. **Clone or view the repository**
   ```bash
   git clone https://github.com/superLane/Blog.git
   cd Blog
   ```

2. **Open locally**
   - Simply open `index.html` in your web browser

3. **Deploy on GitHub Pages**
   - Go to repository Settings → Pages
   - Select "Deploy from a branch"
   - Choose `main` branch and `/root` folder
   - Your site will be live at `https://superLane.github.io/Blog`

## 📹 Customizing Your Video

To embed your own video:

### YouTube Video
Replace the `src` in the iframe:
```html
<iframe src="https://www.youtube.com/embed/YOUR_VIDEO_ID"></iframe>
```

### Vimeo Video
```html
<iframe src="https://player.vimeo.com/video/YOUR_VIDEO_ID"></iframe>
```

### Self-hosted Video
```html
<video width="100%" height="600" controls>
    <source src="path/to/your/video.mp4" type="video/mp4">
</video>
```

## 📝 Customizing Content

1. **Update your bio** - Edit the About section in `index.html`
2. **Add contact links** - Modify the contact section with your actual social media/email
3. **Modify thought cards** - Add your key insights about AI and technology
4. **Change colors** - Edit CSS variables in `styles.css` under `:root`
